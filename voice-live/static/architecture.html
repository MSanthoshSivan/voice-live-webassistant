🔄 Data Flow

User Speech → Microphone → PyAudio → Base64 → Azure API → GPT-4o → TTS → Audio Stream → Speaker → User Hears Response

Parallel: All events broadcast via Socket.IO to update web UI in real-time

🧵 Threading Model

  • Main Thread: Flask web server
  • Socket.IO Thread: WebSocket communication
  • Event Loop Thread: AsyncIO for Azure SDK
  • Audio Capture Thread: Microphone input
  • Audio Send Thread: Upload to Azure
  • Audio Playback Thread: Speaker output
